# Quick Task 260402-13d: AddTodoRow UI Polish — Name Input Visible Affordance Summary

**One-liner:** Underline-style border (border-input/60 at rest, border-ring on focus) applied to both name and date inputs in AddTodoRow's expanded creation form, using only semantic Tailwind tokens.

## What Was Done

Applied targeted className changes to both inputs in the AddTodoRow expanded form:

**Name input** (was `border-0 p-0`, now `border-0 border-b border-input/60 px-1 pb-0.5`):
- Added visible bottom border at rest via `border-b border-input/60` (subtle 60% opacity of the `border-input` token)
- Added minimal padding `px-1 pb-0.5` so text is not flush against the border
- Focus changes border colour to `border-ring` (brand violet) — ring removed as border change alone is sufficient signal

**Date input** (was `border-0 p-0`, now `border-0 border-b border-input/60 px-1 py-0.5 w-full`):
- Same underline treatment for visual consistency
- Added `py-0.5` so the browser renders the native date field segments and calendar icon with enough vertical space to be clickable
- Added `w-full` so the input fills its `w-24` shrink-0 wrapper (was missing, causing narrow rendering)
