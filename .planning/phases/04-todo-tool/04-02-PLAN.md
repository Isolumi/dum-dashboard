**Status icon button (left, per D-13, D-15):**
```tsx
<Button
  variant="ghost"
  size="icon"
  onClick={() => onUpdate({ id: todo.id, status: STATUS_CYCLE[todo.status] })}
  aria-label={`Mark "${todo.name}" as ${STATUS_NEXT_LABEL[todo.status]}`}
  className="shrink-0"
>
  {STATUS_ICONS[todo.status]}
</Button>
```
where `STATUS_ICONS` is a record mapping status to the JSX icon element.

**Name field (center, per D-05, UI-SPEC):**
- Default (not editing): `<span>` with `text-base flex-1 cursor-pointer`, click triggers `setIsEditingName(true)`. If completed: add `line-through text-muted-foreground`.
- Editing: `<Input>` with `autoFocus`, `className="h-auto border-0 shadow-none p-0 focus-visible:ring-1 focus-visible:ring-ring/50 text-base flex-1"` (overrides default Input height per Pitfall 6), `aria-label="Edit todo name"`.
  - `onKeyDown`: Enter saves (call `onUpdate` if changed, then `setIsEditingName(false)`), Escape reverts (`setNameValue(todo.name)`, `setIsEditingName(false)`).
  - `onBlur`: Check `event.relatedTarget` — if it's within the same row (Pitfall 4), skip save. Otherwise, save if value changed, then `setIsEditingName(false)`.
  - `onChange`: update `nameValue` state.

**Priority badge button (right, per D-06, D-14, UI-SPEC):**
```tsx
<Popover open={isPriorityOpen} onOpenChange={setIsPriorityOpen}>
  <PopoverTrigger
    render={
      <button
        className={cn(
          "text-sm px-2 py-1 rounded-sm font-medium shrink-0 cursor-pointer",
          PRIORITY_STYLES[todo.priority]
        )}
        aria-expanded={isPriorityOpen}
        aria-haspopup="listbox"
        aria-label={`Change priority for "${todo.name}"`}
      />
    }
  >
    {PRIORITY_LABELS[todo.priority]}
  </PopoverTrigger>
  <PopoverContent className="w-32 p-1" align="end">
    {(["high", "medium", "low"] as const).map((p) => (
      <button
        key={p}
        className={cn(
          "w-full text-left text-sm px-2 py-1.5 rounded-sm hover:bg-neutral-800",
          PRIORITY_STYLES[p]
        )}
        onClick={() => {
          onUpdate({ id: todo.id, priority: p });
          setIsPriorityOpen(false);
        }}
      >
        {PRIORITY_LABELS[p]}
      </button>
    ))}
  </PopoverContent>
</Popover>
```

CRITICAL: Use `render` prop on `PopoverTrigger`, NOT `asChild`. This project uses base-ui (Pitfall 1). The trigger must be a native `<button>` element passed via `render`, not wrapped with `asChild`.
