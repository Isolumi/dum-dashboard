**Create `src/routes/todos/index.tsx`** -- the full route file with:

1. **Route definition:** `createFileRoute("/_layout/todos/")` with `loader` and `component` per Pattern 1.

2. **Loader:** Calls `getTodos()` (no arguments), returns `{ todos }`. Wrap in try/catch -- if `getTodos()` throws, return `{ todos: [], error: "Could not load todos. Refresh to try again." }`.

3. **Component (`TodosPage`):**
   - Call `Route.useLoaderData()` to get `{ todos: initialTodos, error }` (NOT `useLoaderData()` from module -- Pitfall 2).
   - Seed local state: `const [todos, setTodos] = useState<Todo[]>(initialTodos)`.
   - Track mutation error: `const [mutationError, setMutationError] = useState<string | null>(null)`.
   - Auto-dismiss mutation error after 4 seconds using `useEffect` with timer cleanup.

4. **Mutation handlers** (passed as props to child components):
   - `handleCreate(fields: { name, priority, due_date })`: Guard empty name (`name.trim().length > 0` -- Pitfall 7). Call `createTodo({ data: { name: fields.name.trim(), priority: fields.priority, status: "not_started", due_date: fields.due_date } })`. On success, prepend returned todo to `todos` state. On error, set `mutationError` to "Save failed -- check your connection and try again."
   - `handleUpdate(fields: { id, name?, priority?, status?, due_date? })`: Optimistically update the todo in `todos` state. Call `updateTodo({ data: fields })`. On error, revert to previous state and set `mutationError`.
   - `handleDelete(id: string)`: Optimistically remove from `todos` state. Call `deleteTodo({ data: { id } })`. On error, revert and set `mutationError`.

5. **JSX structure** (per UI-SPEC page structure):

Error state uses `<Alert variant="destructive">` from shadcn/ui per composition.md ("Callouts use Alert, not custom styled divs"):

```tsx
<main className="flex flex-col gap-8 p-6">
  <h1 className="text-xl font-semibold">Todos</h1>
  {error && (
    <Alert variant="destructive">
      <AlertCircle />
      <AlertTitle>Error</AlertTitle>
      <AlertDescription>{error}</AlertDescription>
    </Alert>
  )}
  <div className="flex flex-col" role="list">
    <AddTodoRow onCreate={handleCreate} />
    {todos.map(todo => (
      <TodoRow key={todo.id} todo={todo} onUpdate={handleUpdate} onDelete={handleDelete} />
    ))}
    {todos.length === 0 && !error && (
      <div className="flex flex-col items-center gap-2 py-12">
        <CheckSquare className="text-muted-foreground" />
        <p className="text-base text-muted-foreground">Nothing here yet</p>
        <p className="text-sm text-muted-foreground">Add your first todo above.</p>
      </div>
    )}
  </div>
  {mutationError && (
    <Alert variant="destructive">
      <AlertCircle />
      <AlertDescription>{mutationError}</AlertDescription>
    </Alert>
  )}
</main>
```
