## Color

Inherited token system from Phase 1. All components use semantic tokens or scale tokens — no hardcoded values.

| Role             | Token / Semantic Variable     | OKLCH Value           | Usage in This Phase                                                       |
| ---------------- | ----------------------------- | --------------------- | ------------------------------------------------------------------------- |
| Dominant (60%)   | `--color-neutral-950`         | `oklch(0.09 0 0)`     | Main content area background                                              |
| Secondary (30%)  | `--color-neutral-900`         | `oklch(0.13 0 0)`     | Sidebar background (`--sidebar`), placeholder bento card background       |
| Surface elevated | `--color-neutral-800`         | `oklch(0.20 0 0)`     | Sidebar active item background fill, bento card hover state               |
| Border           | `--color-neutral-700`         | `oklch(0.28 0 0)`     | Sidebar border, bento card borders, layout dividers                       |
| Text primary     | `--color-neutral-100`         | `oklch(0.93 0 0)`     | Sidebar item labels, app name, bento card text                            |
| Text muted       | `--color-neutral-400`         | `oklch(0.60 0 0)`     | Placeholder bento card secondary text ("placeholder" label)               |
| Accent (10%)     | `--color-violet-500`          | `oklch(0.65 0.2 270)` | Active sidebar nav item (background fill + text/icon colour override)     |
| Accent hover     | `--color-violet-400`          | `oklch(0.70 0.2 270)` | Hover state on active nav item; hover state on bento cards (border glow)  |
| Destructive      | `--destructive`               | `oklch(0.577 0.245 27.325)` | Not used in Phase 2 (no destructive actions)                        |

**Accent (`violet-500`) reserved for:**

- Active sidebar nav item — background fill and text/icon tint (via shadcn `isActive` prop + CSS override on `--sidebar-primary`)
- Focus rings on interactive elements (already wired via `--ring: oklch(0.65 0.2 270)`)

Accent is NOT applied to: inactive nav items, bento card borders, bento card text, placeholder labels.

**Sidebar colour token overrides** (set in `src/styles.css` `:root`, already in place from Phase 1):

```
--sidebar:                  oklch(0.13 0 0)   /* neutral-900 */
--sidebar-foreground:       oklch(0.93 0 0)   /* neutral-100 */
--sidebar-primary:          oklch(0.65 0.2 270) /* violet-500 — active item accent */
--sidebar-primary-foreground: oklch(0.93 0 0)
--sidebar-accent:           oklch(0.20 0 0)   /* neutral-800 — hover fill */
--sidebar-accent-foreground: oklch(0.93 0 0)
--sidebar-border:           oklch(0.28 0 0)   /* neutral-700 */
--sidebar-ring:             oklch(0.65 0.2 270) /* violet-500 */
```

These sidebar variables are already set in `src/styles.css`. No new token declarations needed.

Source: Phase 1 UI-SPEC §Colour, `src/styles.css` `:root` (confirmed present), 02-CONTEXT.md §Active nav indicator.

**Hard constraints (inherited, non-negotiable):**

- No hardcoded hex, rgb, hsl, or oklch values in any `.tsx` or `.ts` file.
- No raw Tailwind default palette classes (`gray-*`, `slate-*`, `blue-*`, etc.).
- No `dark:` utility prefixes — dark mode only; single theme.

## Layout Specification

### Pathless Layout Route

- File: `src/routes/_layout.tsx`
- Contains: `<SidebarProvider>` wrapping `<AppSidebar />` + `<SidebarInset>` with `<Outlet />`
- `__root.tsx` remains a bare HTML wrapper — no sidebar at root level

### Sidebar Dimensions

| State     | Width  | Content                                               |
| --------- | ------ | ----------------------------------------------------- |
| Expanded  | 240px  | Icon (24px) + 8px gap + label (14px, weight 400)      |
| Collapsed | 56px   | Icon (24px) centred; no label; tooltip on hover       |

Sidebar is persistent and collapsible (icon-only when collapsed). No mobile/drawer behaviour in Phase 2.

### Sidebar Structure

```
SidebarHeader
  └── LayoutDashboard icon (24px) + "Dashboard" label (14px, semibold)

SidebarContent
  └── SidebarGroup
        └── SidebarMenu
              └── SidebarMenuItem (per registry entry)
                    └── SidebarMenuButton (isActive, asChild with TanStack Link)
                          └── <Icon> + <span>{label}</span>

SidebarRail (collapse toggle)
```

- App header icon: `LayoutDashboard` from lucide-react, 24px
- Nav item icon: each tool's `icon` from registry, 20px
- Active state: shadcn `isActive` prop on `SidebarMenuButton` — uses `--sidebar-primary` (violet-500) automatically
- No custom left border or extra chrome on active item

### Bento Grid (Overview Page `/`)

| Breakpoint | Columns | Gap   |
| ---------- | ------- | ----- |
| sm (640px) | 1       | 16px  |
| md (768px) | 2       | 24px  |
| lg (1024px)| 3       | 24px  |

- Grid container padding: 24px (lg token)
- Each bento card: full column width, minimum height 160px
- `PlaceholderBentoCard` background: `bg-neutral-900`, border: `border-neutral-700`, border-radius: `rounded-lg` (from `--radius-lg`)

## Interaction Contract

| Interaction                           | Behaviour                                                                                              |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Sidebar collapse toggle               | `SidebarRail` component handles toggle; width animates between 240px and 56px                         |
| Nav item hover (expanded)             | Background fill to `--sidebar-accent` (neutral-800); no colour change on text/icon                    |
| Nav item hover (collapsed)            | Tooltip appears with item label; background fill to `--sidebar-accent`                                |
| Nav item active (current route)       | `isActive` prop on `SidebarMenuButton`; background fill + text/icon to `--sidebar-primary` (violet-500) |
| Nav item click                        | TanStack Router `Link` via `asChild` prop — client-side navigation, no full reload (NAV-02)            |
| Bento card hover                      | `border-violet-400` border colour transition (150ms ease); cursor pointer                              |
| Bento card click                      | Navigate to tool route via TanStack Router `Link` wrapping the card                                   |

No scroll interactions, no modals, no forms in Phase 2.
